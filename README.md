# Blawsa downloads

Installers for [Blawsa](https://blawsa.web.app), a fast, native Mac browser with spaces, pinned tabs and Peek. Built on Chromium.

**[Download the latest version](https://github.com/frimpongopoku/blawsa-releases/releases/latest/download/Blawsa.dmg)** (Apple Silicon and Intel, macOS 15 or later).

Blawsa updates itself, so you only need this once.
